# 情感设计：四层、衰减曲线与触发规则

这份文档补上「情感」缺的两块：**每一层怎么衰减**、**什么话会触发什么变化**。

## 一、四层状态

| 层 | 变量 | 范围 | 时间常数 τ | 半衰期 | 谁能改 |
|---|---|---|---|---|---|
| 情绪 | `emotion.intensity` + label | 0–100 | 30 秒 | ≈ 20.8 秒 | 规则 / 模型 / 衰减 |
| 心情 | `mood` | 0–100 | 2 小时 | ≈ 1.39 小时 | 规则 / 模型 |
| 精力 | `energy` | 0–100 | 3 小时 | ≈ 2.08 小时 | 规则 / 模型 |
| 好感 | `affection` | 0–100 | 按事件（EMA α=0.05） | 约 30 天量级 | 规则 / 模型 |
| 性格 | 提示词里的固定描述 | — | 不变 | — | 只读 |

数值全部存 SQLite（`persons` 表），重启不丢；模型只能给「变化量」，不能直接写值。

## 二、衰减曲线

全部是指数衰减：`x(t) = 目标 + (x₀ − 目标) · e^(−t/τ)`。

```
心情：mood ← mood + (baseline − mood) · (1 − e^(−Δt/2h))
基线：baseline = 50 + 0.2 × (affection − 50)     // 越喜欢，基线越高
精力：energy ← energy + (50 − energy) · (1 − e^(−Δt/3h))
情绪：I ← I · e^(−Δt/30s)，损耗的强度按 0.3 并入 mood
好感：affection ← affection + 0.05 × (目标 − affection)   // 每次事件，不是按时间
```

半衰期换算（`t½ = τ·ln2`）：

| 层 | τ | 半衰期 | 1 小时后剩多少 |
|---|---|---|---|
| 情绪 | 30 s | 20.8 s | ≈ 0 |
| 心情 | 2 h | 1.39 h | 约 70% 的偏离量 |
| 精力 | 3 h | 2.08 h | 约 79% |
| 好感 | 事件驱动 | — | 几乎不动 |

举例：被骂一句，心情从 50 掉到 47（−3）。

```
t=0      47.0
t=30s    47.0   （心情几乎不动，情绪先散）
t=5min   47.0
t=1h     48.9   （回了一半多）
t=6h     49.9   （基本回到基线）
```

情绪则是几秒就没了：`I=60` 的情绪，30 秒后剩 22，60 秒后剩 8。

## 三、触发规则（确定性层）

规则在模型之前跑，给一个兜底判断；命中最多 2 条，变化量按 **0.5 缩放**，避免和模型 state 双重计入。

| 规则 | 触发词（示例） | 变化 | 标签 |
|---|---|---|---|
| `praise` | 夸、喜欢你、爱你、想你、抱抱、真好 | mood +1，affection +0.5 | 开心 |
| `insult` | 滚、讨厌、闭嘴、废物、骂 | mood −1.5，affection −0.5 | 生气 |
| `apology` | 对不起、我错了、别生气 | mood +0.5，affection +0.5 | 松快 |
| `coquette` | 嘛、好不好、陪我、撒娇 | mood +0.5，affection +0.5 | 松快 |
| `tired` | 累、加班、难受、想哭、撑不住 | mood −1，energy −1 | 低落 |
| `goodnews` | 开心、太好了、成功了、升职 | mood +1 | 开心 |
| `night` | 晚安、睡了、困了 | energy −0.5 | 平静 |
| `reunion` | 好久不见、想你了 | mood +1，affection +0.5 | 开心 |

之后模型可以给 `state` 覆盖：单轮上限 `mood ∈ [−6, +3]`、`energy` 减半后 `[−5, +1]`、`affection` 原值；中性/难受的回合不接受正向 mood。所有值最终钳在 0–100。

## 四、优先级

```
1. 规则层（关键词，±0.5~1.5）        ← 兜底，保证不会完全没反应
2. 模型 state（语义判断，上限 ±6）    ← 主判断
3. 时间衰减（每次 tick 结算）        ← 负责回落
4. 情绪标签：模型给 valence 则按 valence 定，否则用规则标签
```

## 五、为什么这样分层

- **情绪**是「这一句的反应」，只影响标点、语气词、表情；
- **心情**是「这一阵子的底色」，影响话多话少、热不热络；
- **好感**是「对这个人」，影响称呼、距离、主动性；
- **性格**是「它本来是谁」，决定上面三层的活动范围。

一句话：**性格和好感决定大体，心情和情绪决定细节。**
